# UX/UI Exam Trainer (Ch 2, 3, 4, 5, 8, 9)

เว็บติวสอบวิชา UX/UI: ข้อสอบจำลอง 5 ชุด × 60 ข้อ (300 ข้อ) เลือกภาษา EN / ไทย / สองภาษา, Study Guide, Cheat-Sheet, PDF และพอดแคสต์

- `index.html` – ข้อสอบ (โหมดฝึก/โหมดสอบ, สลับตัวเลือก, คะแนนรายบท, ทบทวนข้อผิด/ติดดาว)
- `Study-Guide.html`, `Cheat-Sheet.html` – สรุปเนื้อหา
- `pdf/` – Exam Pack (EN และ EN+TH) และ Study Guide
- `podcast/` – พอดแคสต์ 6 ตอน + สคริปต์

เนื้อหาสรุปจากสไลด์ประกอบการเรียน ข้อสอบเป็นข้อสอบจำลอง ไม่ใช่ข้อสอบจริง
